# Personal Portfolio Website

A responsive personal portfolio website showcasing my background, technical skills, projects, education, and contact information as an Information Technology student.

## Features

- Responsive layout for desktop, tablet, and mobile devices
- Black-and-yellow visual theme
- Navigation links to different portfolio sections
- About Me section
- Technical skills showcase
- Project portfolio
- Educational background
- Contact section
- Scroll reveal animations
- Active navigation highlighting
- Mobile navigation menu
- Automatic copyright year

## Built With

- HTML5
- CSS3
- JavaScript

## Project Structure

```text
portfolio/
├── index.html
├── style.css
├── script.js
├── README.md
└── profile.jpg
```

## Getting Started

1. Download or clone the project.
2. Open the project folder in your code editor.
3. Place your profile picture in the `image` folder and name it `profile.jpg`.
4. Update the portfolio content with your personal information.
5. Open `index.html` in your web browser.

## Customization

You can customize the website by editing the following files:

- `index.html` — Update your profile, skills, projects, education, and contact details.
- `style.css` — Modify colors, fonts, layouts, and animations.
- `script.js` — Adjust navigation behavior and interactive features.
- `profile.jpg` — Replace the sample profile image with your own photo.

Before publishing, replace any placeholder email address and project information with your actual details.

## Deployment

This is a static website, so it can be hosted using services such as GitHub Pages, Netlify, or Vercel.
